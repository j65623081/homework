# Домашнее задание после занятия 1

**Работайте прямо в этой папке.** Здесь уже лежат правила, по которым будет
работать ваш агент, материалы занятия и заготовки файлов, которые вы сдадите.

## Шаг первый

Запустите агента **в этой папке** — приложением, расширением для редактора
или из терминала, как вам привычнее. Первым делом попросите его осмотреться:

```
Осмотри эту папку: какие файлы здесь лежат, что в них написано и что от меня
требуется. Скажи, с чего начать и какие правила ты теперь обязан соблюдать.
Ничего не меняй — сначала расскажи.
```

Агент прочитает `CLAUDE.md`, через него подтянет `AGENTS.md` и дальше будет
работать по этим правилам сам, без напоминаний в каждом сообщении.

Если в ответе нет ни слова про журнал работы, план до правок и доказательство
вместо «готово» — правила не подхватились. Проверьте, что агент запущен именно
в этой папке, а не уровнем выше.

## Что здесь лежит

| Файл | Зачем |
|---|---|
| `homework.pdf` | Само задание: цикл работы, обязательная часть, семь ролевых задач, критерии |
| `AGENTS.md` | Правила. **Часть I** — требования курса, оставьте как есть. **Часть II** — ваша, её нужно расширить под свою задачу |
| `CLAUDE.md` | Точка входа для Claude Code: подключает `AGENTS.md`. Дорабатывать нужно не его |
| `SPEC.md` | Заготовка спецификации. Заполняется на втором шаге, вместе с агентом |
| `sessions/` | Журнал работы: файл на сессию, плюс `STATE.md` и `TOOLS.md` |
| `materials/` | Материалы занятия: `getting-started`, `lesson-01`, `reference`, `transcript` |

Материалы есть в двух видах: `.pdf` — читать самому, `.md` — давать агенту.
Второе не формальность: агент, прочитавший конспект занятия, заметно точнее
понимает, чего вы от него хотите.

## Про правила

Часть I в `AGENTS.md` — базовый минимум, одинаковый для всех. Ваша работа —
**расширить его**: вписать стек и команды запуска, свои запреты, случаи,
когда агент обязан остановиться и спросить, и проверки, которые он выполняет
перед словом «готово».

Заготовки в Части II намеренно общие. Файл правил, в котором ничего не дописано,
засчитан не будет: половина задания в том и состоит, чтобы понять,
какие ограничения нужны именно вашей задаче.
