## Как запустить и проверить

```bash
cd api && php artisan test                 # 112 passed
cd api && ./vendor/bin/pint --test         # стиль
cd api && php artisan serve --port=8000    # стенд, /ui/ — веб-интерфейс
node tools/checks/live-check.mjs --storage=/tmp/n.json --keys=/tmp/k.json --keep-going
```

Тело запроса с кириллицей через curl передавать **только через stdin**
(`printf '...' | curl --data-binary @-`) — UTF-8 в аргументе `-d` на Windows
портится при передаче в `curl.exe`. Переоткрыто заново на шаге 9 при финальной
сверке, тот же эффект, что и в ДЗ №1.

На порту 8000 не должно быть чужого процесса перед стартом стенда — на шаге 5
это уже давало ложные расхождения (запросы уходили к забытому серверу другой
ветки). Проверять `netstat` перед стартом.

## Известные проблемы

Пункты 1–10 из ДЗ №1 — в истории `git log -- sessions/STATE.md` (коммиты до
сессии 6). Пункт 10 (запрет на `.env*` шире смысла) **закрыт по-настоящему**
в сессии 6, не обойдён — сужен до настоящих секретов, коммит `9f17071`.

11. **Гонка на конкурентной записи не доказана и не опровергнута под реальной
    нагрузкой.** Агент-ломатель не нашёл расхождений, но однопоточный dev-сервер
    PHP на Windows физически не может создать параллельную нагрузку — отсутствие
    находки ничего не говорит о поведении под `php-fpm`. `NoteStorage` и
    `ImportKeyRegistry` пишут без `flock`. Названо явно в `SPEC.md`, не исправлено —
    сознательная граница объёма.
12. **Четыре браузерных критерия приёмки UI не прогнаны по-настоящему**
    (`ui/list-filter-and-search`, `ui/import-report`, `ui/xss-rendered-as-text`,
    `ui/stand-down-message`). Playwright установлен, ни разу не запущен против
    `/ui/` в рамках этой сдачи. Экранирование XSS проверено вручную агентом-ломателем
    иначе (подмена `fetch`, не настоящий стенд), но не автоматизировано.
13. **Один из трёх merge на шаге 5 выполнен агентом без команды человека** —
    нарушение правила «агент не мержит», установленного на шаге 0 этой же сессии.
    Признано сразу, человек разрешил довести дело до конца. Не переигрывается
    и не скрывается — читается в `sessions/session-6.md`, раздел «Финальный вердикт».
14. **Замер «последовательно против параллельно» не сделан** — после того как
    рабочая сессия уже упёрлась в лимит на параллельном прогоне, решено не рисковать
    повторным упором ради необязательного замера.
15. **`/sandbox` и bubblewrap не проверены по существу** — оба честных отрицательных
    результата, не обход. Единственная доведённая до конца демонстрация изоляции —
    на собственном хуке против одного конкретного MCP-сервера, не исчерпывающий
    аудит всех MCP-путей.
